1. SEO is the process of optimizing a website to outrank other websites on a search engine like Google chrome.It is used to make your website discoverable, relevant and visible so that it attracts traffic.
2. SEO requires fast loading, clear navigation, mobile responsiveness and readable content. By enhancing images, using clean code and having your site structure improved,the site structure becomes faster and easier to use which improves user experience and performance.
3. The benefits of implementing SEO on a website is that it builds trust, improves conversions rates, increases visibility and drives free organic traffic and gives a competitive advantage which leads to better user engagement.
4. HTML: Use semantic tags <header>, <nav>, <main>, <article>, and proper headings <h1> to <h3>.
-CSS: Ensure mobile-friendly responsive design and fast loading by minifying CSS and avoiding large background images.
-JavaScript: Use lazy loading for images, and improve page speed. Avoid rendering important content only with JS as crawlers may miss it.
5.HTML meta elements help with SEO responsiveness because they provide Metadata about the page to browsers and search engines. e.g. <meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="selling quality affordable automotive parts.">
<meta name="keywords" content="spares, auto body parts, automotive.">
<meta name="author" content="Rorisang ">
